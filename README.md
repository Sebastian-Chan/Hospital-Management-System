#** Hospital Management System**
This project is a console-based application developed in Java, designed to simulate and manage essential hospital operations, including patient registration, room assignments, medical appointments, prescriptions, and patient history tracking.

The project focuses on implementing object-oriented programming (OOP) and fundamental data structures, such as arrays, linked lists (singly, doubly, and circular), stacks, and queues.

It demonstrates practical applications of data structures, efficient information management, and logical problem-solving in a healthcare environment.
